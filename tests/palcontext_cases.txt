# Test cases for GLAMODAT.core.distance_calculation._condition_met_for_palcontext
#
# One case per line, columns separated by "|" (spaces around the values are ignored, so keep the table aligned).
# Lines starting with "#" and empty lines are skipped.
#
# Conventions (same as inside GLAMODAT):
#   ages        : positive years before present (b2k), growing into the past
#   current_t   : age of the model frame that is evaluated
#                 ice margin / ice free -> the first frame with age <= min_age (process_features), so usually
#                 a bit younger than min_age; == min_age only if a frame falls exactly on it (special case)
#                 ice cover / bedrock exposure -> the last frame (end_time)
#   last_ice    : lasticecover of the cell at current_t
#                 negative = ice free since |last_ice| years, positive = ice covered since last_ice years
#   cum_icefree : icefree_cummulative of the cell at current_t (total ice-free years), only used by bedrock exposure;
#                 "-" = not used by this category
#   t_before    : age of an earlier model frame: the youngest frame with age >= min_age (the last frame still inside
#                 the window). Only for special cases where last_ice at current_t is not enough, because
#                 lasticecover only remembers the last change; "-" = only the frame at current_t is used
#   last_ice_before : lasticecover of the cell at t_before; "-" = not used
#   expected   : what the function SHOULD return (physical meaning, not what the code currently does)
#   explanation : what the case means. If it contains "KNOWN ISSUE:", the code currently disagrees with
#                 "expected" and the test is xfail (strict: it fails once the code is fixed, then remove the note).
#
# group = baseline -> two simple cases per category (one match, one mismatch)
# group = special  -> edge cases, added later
